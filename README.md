# RaskovaMLVelocityHold
Short Experimentation with the stability characteristics of my senior design plane. Stability derivatives pertinent to a velocity hold were run through a DDPG algorithm to be able to see if the model could converge on a way to keep velocity constant, given a perturbation. Derivatives were gathered in FLOW5 and MATLAB. Accreditation in README.

Stability Derivatives gathered in collaboration with Project Night Witch Team. Specifically, Barjeet Singh and Vidit Charvarkar assisted in verification of derivatives.
